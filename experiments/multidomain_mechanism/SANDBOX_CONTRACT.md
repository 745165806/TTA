# Multi-domain mechanism sandbox contract (v0)

`build_sandbox.py` created these assignments once with `random.Random(2026)` after sorting explicit sample IDs or explicit source groups. It writes with exclusive creation and refuses to redraw. The selected counts are In-the-Wild 512, Codecfake official dev 512, ASVspoof2021 LA 282, ASVspoof2021 DF 370, WaveFake 0 blocked. ASV count is below 512 because complete source groups, rather than individual records, were assigned to keep the final holdout group-disjoint.

All `*_mechanism_select.json` records have sample ID, dataset ID, original split, root key, root/path reference, seed, and policy. They have no label, raw-label, attack, or correctness fields. Adaptation workers may open **only** the select manifests. The matching audit manifests are metadata copies with a label-source reference and `label_status=DEFERRED_UNTIL_SCORES_COMPLETE`; they must be opened by the analysis stage only after every expected score file has passed exact ID coverage and finite-value checks. Audit labels are not materialized yet. This prevents accidental use of labels during adaptation.

For In-the-Wild, all 512 IDs come from the existing target10 select manifest. The target10/target90 boundary remains unchanged. For Codecfake, the explicit official dev protocol supplies filenames; its label and attack columns are ignored during selection. For ASV LA/DF, the explicit `source_group_id` assignments are shuffled with seed 2026; mechanism groups are saved in the manifest. **Final holdout means the complement of those saved group IDs in the same official eval pool.** The complement is never relabeled or reshuffled. Neither eval label file was opened to make the split. WaveFake is a blocked placeholder until a reader, explicit label mapping, and production-compatible features exist.

The local feature caches are read-only. ASV and In-the-Wild have production feature caches; Codecfake and WaveFake currently do not. Missing feature paths must be reported as `NOT_RUN`; scores and metrics must never be fabricated. Source-anchor memory is source-only. Per-sample EP state is reset. `0=bonafide`, `1=spoof`, and larger scores mean spoof.

The mechanism sandbox is development data. It is not the final held-out benchmark. Final holdout labels remain closed until method lock. The historical target90 assignment is never changed, and target90 sample labels/metrics remain closed until method lock.
