# Normalized-margin v0-B retired — 2026-09-27

`v0b_20260927T042152Z` completed fixed sandbox scoring and post-score audit. It strongly protected source-anchor margins: macro evidence damage was `0.247588` for Base and `0.00000116` for Base + Preserve. It also reduced harmful threshold flips on the single-class ASV groups. But on the only two-class domain, In-the-Wild, EER remained `0.103960` versus Frozen `0.099010`, and AUC dropped to `0.956404` versus Frozen `0.957841` and Base `0.958783`. The preservation loss often overrode target view improvement and increased score change magnitude (macro mean absolute delta `0.180887` versus Base `0.048707`).

This loss is **not retained as an active EPDC component**. The source implementation is archived under this experiment for reproduction and removed from production `src`. Its negative result is evidence that preserving source-threshold margins alone does not guarantee task-useful target ranking. A gate or continual accumulator is not built on this candidate. The next design must improve the unlabeled target objective itself and must be evaluated with two-class, group-disjoint multi-domain development samples before any method lock.
