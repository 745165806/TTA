# Local WaveFake resource audit — 2026-09-27

This is a local data audit, not a capacity or TTA result. Source: `/media/dell/data/fakedata/WaveFake/data`. `pyarrow 21.0.0` opened 131 Parquet files (30,277,547,105 bytes) with one identical schema: `audio` struct (`bytes`, `path`), `audio_id`, and `real_or_fake`. There are 104,800 rows and 13,100 distinct `audio_id` values. Every ID has exactly one row for each of `R`, `WF1` … `WF7`, entirely within one partition. The explicit `real_or_fake` values and paired `audio_id` are the only locally stored provenance for class and related content; there is no separate transcript, speaker, language, or generator metadata field.

All 104,800 embedded audio payloads were checked through WAV headers. Every row is `.wav`, mono, 22,050 Hz, uncompressed 16-bit PCM; no invalid WAV was found. Thus sample rate, container, channel count and codec **do not separate `R` from `WF1`…`WF7`** in this local resource. All rows need the same explicit deterministic 22,050→16,000 Hz compatibility path before the unchanged production loader. The `audio.path` field is a basename and repeats across generator codes; extraction must reference the Parquet file/row/`audio_id`/generator code, never this basename alone.

Duration is closely matched by content but shows small systematic offsets: median `R` 6.7641 s; WF1/2/4/5/6/7 6.7686 s; WF3 6.7570 s. The corresponding p05/p95 ranges are about 2.68/9.72 s. This is a **residual duration or generation-boundary cue**, even though the main recording format is matched. The production 64,600-sample crop/pad may interact with that cue; the capacity interpretation must remain conditional on this resource. Speaker/language independence cannot be certified because those fields are absent. `audio_id` suggests content pairing, but no text/transcript field allows independent verification of exact semantic equivalence.

**Audit conclusion:** A two-class, related-content paired development assignment is feasible without a rate/codec confound. The study must use group-held-out folds by `audio_id`, report the duration caveat, and never present this source as an unconfounded final generalization benchmark. No data was downloaded or modified. Full counts and duration summaries: `wavefake_audit.json`.
