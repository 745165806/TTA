# Local Distribution TTA hypothesis test, v0

This study tests **shared local target context**, not a proposed final method. The source SSL-AASIST encoder, source-only anchor geometry, safe views, original-view score, and 8×8 EP adapter are fixed. The seven arms are Frozen, per-sample production `ep_no_keep`, per-sample O1, Local-Base B16/B32, and Local-O1 B16/B32. `K=5`, `lr=0.03`, `rho=0.1`; no sweep, preservation, gate, pseudo-label BCE, class balance, prior regularizer, or continual memory is present.

For an ordered buffer `B_j` from **one domain** and one fresh `R_j=0`, Base minimizes `L_j(R)=|B_j|⁻¹ Σ_{i∈B_j} view_loss(z_i(R))`. O1 minimizes `L_j(R)=|B_j|⁻¹ Σ_{i∈B_j} L_O1,i(R)` with the unchanged source-affinity definition in `experiments/task_objective_discovery/OBJECTIVE_O1.md`. The projected SGD update is `R←Π_{||R||F≤0.1}(R−0.03∇_R L_j)` for five steps. All samples in `B_j` are scored with the same final `R_j`; the next buffer allocates a fresh zero matrix. There is no optimizer object or momentum state. `B=1` must reproduce the corresponding per-sample objective and score. `K=0` must reproduce Frozen scores exactly.

Buffers use the saved sorted manifest order, no shuffle and no label/attack/path semantics. ITW and Codecfake are buffered independently. A final partial buffer is kept with its actual size. Source-anchor labels may be used only inside the frozen source resource; target labels never enter the worker. Buffer membership and order are fixed before scores and never changed using metrics. This test is materially different from unbounded continual adaptation because neither `R` nor any optimizer state crosses a buffer boundary.

The full two-domain score generation is gated on the Codecfake compatibility cache passing native 16-kHz parity and exact 512-ID coverage. The analysis code must confirm all seven score arms and finite buffer diagnostics for **both** domains before opening selected-only audit labels. One-domain or one-class output cannot promote the local-context hypothesis. Paired bootstrap uses 1,000 stratified development-only replicates with seed 2026 and is not a final statistical claim.
