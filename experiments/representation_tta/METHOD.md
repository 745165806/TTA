# Representation-level SSL-AASIST TTA method contract

Branch: `exp-representation-tta`, based on `exp-overnight-tta` (`f58f3c2`). This branch is isolated from the dirty root worktree. The model is the project-trained SSL-AASIST epoch 7 Frozen bundle, with native `spoof=0`, `bonafide=1` two-logit ordering and spoof-positive score `logits[:,0]-logits[:,1]`.

## Measured placement

The author model's XLS-R frontend produces `[B,201,1024]`. Its task-trained `LL` layer produces `[B,201,128]`, immediately before max pooling, RawNet2 convolutions, spectral/temporal attention, graph attention, 160D readout, and the final classifier. A one-waveform GPU probe found exact logits equality when this `LL` tensor was fed through the unmodified author backend after replacing only the SSL extractor and LL projection with identity/pass-through modules. This is an earlier representation sequence, never the final 160D cache.

Route A uses a shared 128→64→128 bottleneck residual adapter on each time frame, with a zero-initialized second projection and 16,576 trainable parameters. All SSL, AASIST backend and original classifier parameters and buffers remain frozen in eval mode. On source fit, train the candidate with BCE on the same original/noise audio views plus `0.05 ×` supervised contrastive loss on pooled adapted 128D sequences (temperature 0.1). Train an equal-step, equal-batch, equal-view static adapter with BCE alone. Both start with identity adaptation and use the same source batch schedule. Train five complete passes through the source spoof fit examples, with balanced bonafide resampling; source select clean EER, then mean noise/FIR EER, then clean AUC selects an epoch. Do not use target labels for source training or checkpoint selection.

At target time, freeze the candidate's source-trained backend/classifier and update only its 16,576 adapter parameters. Retain source fit pooled `[128]` prototypes for bonafide and each official A01–A06 spoof family. The detached source-only score marks high-confidence pseudo-classes (`p≥0.9` spoof or `p≤0.1` bonafide). The target objective is `0.1 L_anchor + 0.05 L_view + 0.01 L_move`: class-conditional normalized mean-squared distance to source prototypes, original/noise/FIR logit consistency normalized by source score variance, and relative adapter parameter displacement. No target labels, sample IDs, filenames, generator codes, true class proportions, or cross-domain state enter `adapt_unlabeled`. Two complete unlabeled passes, batch size 64, Adam LR 1e-4, gradient-norm clip 1.0. The final shared adapter scores every sample of its domain. ITW and WaveFake restart separately from the same source checkpoint. This is **offline batch-transductive** and retains source prototypes; it is not source-free, online, single-sample, or episodic EP-TTA.

The first source/target run is seed13. Four required comparisons are Frozen, equal-budget BCE static adapter, candidate source-only adapter, and the same checkpoint after target adaptation. Only on-vs-off gain is attributable to TTA. AUC, EER, source-select threshold FPR/FNR, runtime, GPU memory, numerical failures, and content-pair WaveFake paired bootstrap are saved with all ID-level scores. If seed13 on-vs-off improves a domain by ≥0.005 AUC or ≥0.005 absolute EER without an equal degradation in the other domain, run seeds29/47/71 and one necessary ablation; otherwise consider at most one genuinely distinct earlier-layer placement. Only one explicit development-informed revision is allowed. No target90/final holdout.

The `tta` GPU probe succeeded only outside the default sandbox because `/dev/nvidia*` is absent inside it; GPU commands request escalation. The full fixed-assignment LL cache build was rejected twice by automatic approval review despite explicit user authorization and measured 12.76 GiB projected cache against 692.7 GiB free. It has **not run**. No indirect substitute or workaround has been used.
