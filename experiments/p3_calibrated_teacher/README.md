# Archived P3 development tools

This directory retains the label-free two-component score calibrator, the
independent per-sample calibrated selective episode, paired statistical helper,
and small historical reports from `exp-p3.1-stat-asym` at
`2f0b82cfefa366f4e411c318f6b8f11b32d1e7a1`.

The original calU/evalU assignment, run launchers, per-sample scores and full
logs remain at `archive/20261010/exp-p3.1-stat-asym`. The historical assignment
was generated by SHA ordering, so this integration tree does not include the
split generator or regenerate that assignment. These modules are analysis and
method components, not an end-to-end runner or a registered default method.
No target labels, prior target scores or attacks enter the `run` interface.
The target GMM must be fit from an explicitly assigned unlabeled calibration
role; its `tau_hat` never replaces the source `tau0` in source-anchor safety.

Read `reports/statistical_reanalysis.md` after `reports/main_run.md`: the
original favorable point estimate did not survive the required paired
bootstrap interval test. `reports/followup.md` documents further sensitivity
and class-asymmetry negatives. These are target10 development results, not a
final holdout claim. No P3 study was rerun for this integration.
