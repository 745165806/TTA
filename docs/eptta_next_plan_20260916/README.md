# EP-TTA 后续执行包

日期：2026-09-16；项目版本保持0.1.0。

先把 `00_PLAN.md` 和 `01_START_NOW.txt` 交给能够访问项目的编码AI。
首轮只做审计、恢复准备及必要代码开发，不自动重启训练或评分目标。
后续按阶段授权，不一次性粘贴全部工单当作无限资源授权。

| 文件 | 用途 |
|---|---|
| 00_PLAN.md | 完整研究、数据、恢复、实验、代码与验收方案，含公开依据 |
| 01_START_NOW.txt | 现在即可发送的首轮指令 |
| 02_RESUME_AND_FREEZE.txt | 批准真实恢复计划后，训练收尾、FINALIZED、R4 |
| 03_SOURCE_PILOT.txt | 批准源先导后，R5/R6最小真实实验 |
| 04_EXPAND_AND_SEAL.txt | 补底座/seed/基线、目标接入、R7封存 |
| 05_SCORE_AND_EVALUATE.txt | 批准R7实际plan后，R8/R9无标签评分与评价 |
| SHA256SUMS.txt | 本执行包文件的完整性清单，不是项目实验审批hash |

后续指令中的 `<实际完整hash>` 需替换为项目AI生成并经你审阅的计划身份。
这些是自然语言任务指令，不是shell命令，不能直接粘贴进终端。
本包没有访问你的远程仓库或训练环境，没有运行项目测试，没有恢复模型。
本轮文件验收仅覆盖UTF-8读取、相对文件引用、工单覆盖、hash及ZIP完整性。
报告中的当前数量和训练进展来自用户描述；执行AI应现场核实。

本包不包含新的划分程序或训练框架：要求AI复用现有代码，仅补真正缺口。
它也不撤销现有数据lock；是否保留取决于科学/权限审计，而不是lock本身。
旧执行文件保留为历史，本包更新的是后续启动与测试安排。
