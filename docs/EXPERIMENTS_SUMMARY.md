# EP-TTA 全部实验结果详细汇总（表格版）

> 生成时间：2026-09-21
> 数据来源：`docs/` 各阶段报告、`outputs_v2/` 各 `metrics.json` 与汇总 CSV、`artifacts/private/` 各对比 CSV、`experiments/target10_selection/` 结果文件。
> 指标语义：`0=bonafide, 1=spoof`，分数越大越偏伪造。EER/FPR/FNR 越低越好；AUROC/TPR 越高越好；HFR（有害翻转率）越低越好。
> 方法名：`Frozen`＝无测试时适应（基线）；`EP-TTA`＝完整 episodic 自适应；`Multi-view`＝同一 3 视图 logit 均值、不更新参数。

---

## 1. 项目与数据角色

| 项 | 内容 |
|---|---|
| 项目 | EP-TTA：假音频检测的 episodic 测试时自适应 |
| 检测器 | AASIST（作者 commit `a04c9863…`）、SSL-AASIST（XLS-R 300M 前端 + AASIST 头，作者 commit `4acaa61d…`） |
| 数据角色 | fit（源训练/源统计）、source_val（选模）、select（源域选参）、cal0（源域阈值）、control_test（同域测试）、target_test（跨域测试） |
| 标签方向 | `0=bonafide, 1=spoof`，score = `logit_spoof - logit_bonafide`，越大越偏伪造 |
| EP 语义 | 每条样本重置、独立 R 不跨样本/跨卡归约；K 步后对原输入视图评分；不使用目标标签/攻击/整体统计 |

- 两者 EER 差异 ~5.6e-5（第 5 位小数），基本等价。
- 候选 lr 仅为 1e-5~1e-4，自适应几乎不动分数（entropy_reduction 均为微小负值），因此 argmax 规则确定性选择 K=0。

## 6. 总体结论

| # | 结论 | 证据 |
|---|---|---|
| 1 | **工程管线可靠** | 数据构建、冻结导出、缓存/parity、K=0、EP 优化/reset/保护、评价语义全部经真实命令验证 PASS |

| 5 | **待补** | SSL-AASIST 跨域 target 评价；论文 4.1 的 A/B/C/D 协议；tDCF/minDCF（缺 ASV 分数，均标不可用） |
